# SentinelFlow verification checklist

Use this checklist for changes to the fraud-risk demonstration.

- [ ] Verify the application starts with the documented setup.
- [ ] Verify the main risk-analysis flow with representative synthetic data.
- [ ] Confirm validation handles missing or malformed inputs.
- [ ] Confirm explainability output remains readable and consistent.
- [ ] Check that no real financial or personal data is introduced.
- [ ] Review changed files before release.
